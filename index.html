Privacy policy for Wardiva: Phone Manager

Developer: Asoltu Tech
App package on Google Play: com.asoltu.antivirus
Last updated: 2 November 2026
Contact: nikvishi@gmail.com

This policy describes the Google Play version of Wardiva: Phone Manager. It matches how that version is built. Checks run on the phone. Wardiva does not run an account system, does not show ads, and does not include an analytics or crash-reporting service.

1. What this version does not do

The Google Play version does not declare the INTERNET permission, so the app itself cannot open a network connection or upload your files, messages, photos, clipboard, or app list. A library in the build declares ACCESS_NETWORK_STATE. Wardiva does not use that to send or receive your data.

The Google Play version does not request permission to read SMS or phone state, and it does not include an accessibility service. A separate direct-download build can request SMS access. That build is not the one offered on Google Play. Where that build reads messages, it checks them on the phone and does not store or upload the message text.

Wardiva is not a real-time protection product. A result that finds nothing unusual does not mean a link, file, or phone is safe.

2. Data that stays on the phone

The app reads information only for the feature you open, and keeps the result in the app’s own storage on the device. Android backup for the app is turned off. Uninstalling Wardiva removes that app storage.

  • Link and message check. Text you paste is checked on the phone. The check parses the address and looks for warning patterns that are built into the app (for example a brand name on the wrong site, a shortened link, an “http” address, or a request for an OTP). It does not open the link, does not download the page, and does not ask a server what the site is. The result is a list of warning signs. It is never a statement that the link is safe.
  • File check. When you run a scan or share a file into the app, Wardiva computes a SHA-256 fingerprint on the phone and compares it with a list shipped inside the app (about 6,150 entries in this version). A file that is not on the list is not treated as safe. A shared file is copied to the app cache for the check and that temporary copy is deleted when the check finishes. Fingerprints and file names are not uploaded.
  • Installed apps. With the permission to see all apps, Wardiva reads package names, labels, versions, installers, and permissions. It uses this for the permission audit, the sideload and remote-access checks, and the optional “what changed” list. A snapshot and a short change log are stored in the app’s private files. They are not uploaded.
  • Storage and the recycle bin. If you grant All files access, Wardiva can list files on shared storage to show large files, duplicates, and junk, including WhatsApp media folders. Files you choose to remove are moved to a recycle folder in the app’s storage for 7 days, then deleted. You can restore them or delete them sooner. Empty folders have nothing to restore, so those are removed directly. The original path of a binned file is stored in that recycle folder.
  • Cache sizes. If you grant Usage access, Wardiva reads each app’s cache, app, and data size so it can show a list. It does not clear another app’s cache. It opens that app’s system Settings page instead.
  • Security checkup. The checkup reads whether a screen lock is set, the security-patch date, whether USB debugging and developer options are on, which accessibility services are enabled, and which apps look sideloaded or are known remote-access apps. The report stays on the phone unless you choose to share it.
  • Clipboard. If you save copied text, Wardiva keeps it in a private file on the phone (pinned items, plus up to 300 other items). You can delete items in the app. Android only lets the app read the current clipboard while Wardiva is on screen.
  • After a scam. Notes you type, and an optional summary of what is already on the phone, are written into a PDF in the app cache. Wardiva does not send that PDF. If you tap share, Android asks you which app should receive it.
  • Read-aloud. Spoken results use the phone’s own text-to-speech. The text is not sent to Asoltu.
  • Settings. The app stores a few switches on the phone, such as the chosen appearance and whether the app-change check or clipboard saving is on.

If you turn on the app-change check, the app looks at the installed-app list about every 15 minutes and can show a notification on the phone. That check does not send the list anywhere.

3. Permissions

The Google Play version requests:

  • See all installed apps (QUERY_ALL_PACKAGES), for the app list, permission audit, and change check.
  • All files access (MANAGE_EXTERNAL_STORAGE), only after you turn it on in system Settings, for the file scan and clutter tools.
  • Usage access (PACKAGE_USAGE_STATS), only after you turn it on in system Settings, to read cache and storage sizes.
  • Notifications (POST_NOTIFICATIONS), if you allow them, for app-change alerts.

The build also includes library permissions used by the on-device scheduler: wake lock, network-state, receive-boot, and foreground-service. They are not used to upload your data.

4. Sharing that you start

Some screens offer a button that opens a page in your browser, such as cybercrime.gov.in or sancharsaathi.gov.in. That is your browser, not a connection made by Wardiva. Sharing a PDF or a checkup note uses Android’s share sheet. The app you pick then handles that file under its own policy.

5. What we collect

Asoltu Tech does not collect or share user data from this app. There is no Wardiva account, no ad network, and no server copy of your scans, files, messages, or app list. Because nothing is sent to us, there is no Asoltu profile to correct or delete. To remove what Wardiva stored on the phone, delete it inside the app (clipboard items and the recycle bin) or uninstall the app.

6. Children

Wardiva: Phone Manager is a phone utility for adults. It is not directed at children under 13, and we do not knowingly collect personal information from children.
